## Honesty notes for the report

- Spatial CV score (0.711) is the headline; the random-split score (0.812) is shown only to
  quantify leakage.
- The pilot map uses fire history up to 2025, so recent fires shown on top of it are not a
  validation; the validation is the held-out-governorate test.
- The model is unreliable on peri-urban cells (ROC-AUC 0.55 on cells > 10 % built-up); the
  map is valid for wildland only.
- Fire-start locations are satellite first detections: up to ~12 h late and 375 m–1 km
  positional uncertainty.
- Tuning and local-vs-global experiments in `metrics.json` were run before fire history was
  adopted; compare them within each experiment only.
